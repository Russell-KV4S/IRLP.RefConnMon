Do not copy IRLP.RefConnMon.dll.config over your settings if you already set one up.

This build is for macOS on Apple Silicon (M1/M2/M3/M4 and later).
It needs the .NET 10 Runtime (Arm64 installer): https://dotnet.microsoft.com/en-us/download/dotnet/10.0

macOS blocks programs downloaded from the internet that are not notarized by Apple.
After unzipping, open Terminal in this folder and run once:
    xattr -dr com.apple.quarantine .
    chmod +x IRLP.RefConnMon
Then run it with:  ./IRLP.RefConnMon   (or: dotnet IRLP.RefConnMon.dll)

Set Unattended to Y in IRLP.RefConnMon.dll.config and schedule it with cron (crontab -e), e.g. every 2 minutes:
*/2 * * * * cd /path/to/IRLP.RefConnMon && ./IRLP.RefConnMon

Upgrading from 1.2 or earlier: the settings file is now named IRLP.RefConnMon.dll.config instead of IRLP.RefConnMon.exe.config.
Copy your values into the new file (the keys are unchanged). Your existing reflector .txt files still work.
