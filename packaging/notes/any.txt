Do not copy IRLP.RefConnMon.dll.config over your settings if you already set one up.

This build runs on any system .NET 10 supports: Windows, Linux (including Alpine), and macOS, on x64 or ARM.
If there is a zip for your platform (Windows x64, Linux x64, Linux ARM, Linux ARM64), that one is easier to use.
It needs the .NET 10 Runtime: https://dotnet.microsoft.com/en-us/download/dotnet/10.0

There is no double-click program in this zip. Open a terminal/command prompt in this folder and run:
    dotnet IRLP.RefConnMon.dll

Set Unattended to Y in IRLP.RefConnMon.dll.config when running it on a schedule:
- Windows Task Scheduler: Program = dotnet, Arguments = IRLP.RefConnMon.dll, Start in = this folder
- Linux/macOS cron, e.g. every 2 minutes:
  */2 * * * * cd /path/to/IRLP.RefConnMon && dotnet IRLP.RefConnMon.dll
  (cron has a minimal PATH; if it can't find dotnet, use the full path from: which dotnet)

Upgrading from 1.2 or earlier: the settings file is now named IRLP.RefConnMon.dll.config instead of IRLP.RefConnMon.exe.config.
Copy your values into the new file (the keys are unchanged). Your existing reflector .txt files still work.
